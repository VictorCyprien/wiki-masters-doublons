# Visuels du Chrome Web Store

Sources HTML des visuels de `store/`. Les captures brutes viennent de `imgs/` (non versionné) ; `popup-capture.png` est la fenêtre de l'extension rendue à 360 px de large.

Rendu (navigateur à 1×) : viewport 1280×800 pour `1-doublons.html`, `2-tri.html`, `3-fenetre.html` ; 440×280 pour `promo-440.html` ; capture d'écran de la page, enregistrée dans `store/`.
